# Tulip Planner

IP planning and network intelligence tool for subnet calculation, CIDR aggregation, route summarization, allocation planning, and NAT64 translation.

By Moshiko Nayman.

Proprietary software. All rights reserved.

## What Is Tulip

Tulip is a desktop networking utility for working with IPv4 and IPv6 prefixes. It is built for planning address space, checking subnet boundaries, summarizing routes, and modeling allocation usage without mixing that logic with external services.

## Features

- IPv4 and IPv6 subnet calculation from address and prefix length
- CIDR, FLSM, and VLSM subnet planning workflows
- Route aggregation using deterministic sibling-prefix merging
- Allocation tracking with utilization and fragmentation visibility
- RFC 6052 NAT64 translation helpers
- JSON workspace import/export and CSV export
